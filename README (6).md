# CodeAlpha_LanguageLearningApp

Task 4 – Language Learning App (CodeAlpha App Development Internship)

An interactive language learning app built with HTML, CSS and JavaScript (no libraries).

## Features
- Choose a language: **Spanish, French, Hindi or English** (English lessons show simple meanings and grammar rules)
- Categories: **Vocabulary, Phrases and Grammar**
- **Daily lesson** (5 flashcards that change every day) with translation, pronunciation guide and grammar tips
- **Listen** button that speaks the word using the browser's text-to-speech
- **Quiz / practice test** (5 multiple-choice questions) with instant feedback and score
- **Progress screen** showing lessons completed, quizzes taken and best scores
- Progress is saved in the browser using localStorage
- Responsive layout with automatic light/dark mode

## Run
Open `index.html` in any browser. No installation needed.
(The Listen button needs a browser with speech support, such as Chrome or Edge.)
